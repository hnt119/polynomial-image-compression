## PDF production and page review

The main report is five A4 pages, the technical appendix six, and the meeting summary exactly one. They use embedded DejaVu fonts, searchable vector text and equations, consistent margins, page numbers, and explicit source/status labels. Markdown sources retain LaTeX display equations. The editable notation W_cov names the variable called W in TC-G4 so that it cannot be confused with the positive fixed radical W of MS-C1.

The bundled PDF runtime and ReportLab were used offline. Poppler rendered every final page at 110 dpi. The lead visually inspected all 12 final pages individually: equations, signs, subscripts/superscripts, tables, headings, footers, wrapping, page references and margins. The cover preview is an unmodified copy of the final first-page rendering.

One preliminary appendix layout exceeded the page limit; its ledger prose was shortened without removing a claim or source entry. A preliminary font audit detected that the serif font lacked the script-l glyph; the final PDFs explicitly use the embedded sans font for that symbol. Final inspection found no clipped text, overlapping tables, missing glyphs or unreadable equations. Earlier preview images are not deliverables.

The ignored run folder is `local-only/runs/T01/2026-10-11-torsion-frame-freeze/`. It holds the document builder, structured content, source hashes, layout measurements, final page renderings and validation evidence. That builder only lays out supplied text; it performs no mathematical experiment. No reusable research code or tests are changed.
