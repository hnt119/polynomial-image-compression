## C2. Normalization and correlated pair measure

**PROVED — C-NORM.** For s>0,

    P(t+s*x,t+s*y)=2t+s[(x+y)+s^2(x-y)^3].                (C.1)

Thus rescaling the scalar carrier changes the coefficient of the cubic
inside the bracket. It is not an invariance of the fixed normalized
polynomial. Write B=(A-t)/s, lambda=s^2, n=|B|=|A|, and

    Gamma_B={(u,v)=(x-y,x+y): x,y in B},
    F_lambda(u,v)=v+lambda*u^3.

The linear map is invertible, with x=(v+u)/2,y=(v-u)/2. Hence Gamma_B
has exactly n^2 points, each with mass 1/n^2 when the original ordered
pair is uniform. It is generally **not** (B-B) x (B+B). A restriction
to a difference strip changes the conditional pair distribution; its
mass is its actual number of ordered pairs divided by n^2.

Expansion gives, for |h|<=r,

    |(u0+h)^3-u0^3-3u0^2*h|
       = |3u0*h^2+h^3| <= 3|u0|r^2+r^3.                (C.2)

The affine approximation on a strip |u-u_j|<=r is

    ell_j(u,v)=v+3lambda*u_j^2*u-2lambda*u_j^3,
    |F_lambda-ell_j|<=lambda(3|u_j|r^2+r^3).            (C.3)

This formula, including its mass restriction and error, is the actual
cubic-to-projection step. The slopes 3lambda*u_j^2 are generated by the
same pair differences; they are neither independent random directions
nor known to avoid an exceptional set of a projection theorem.

## C3. Fully charged finite covering-to-cardinality implication

Let N_delta^grid denote the number of occupied half-open grid intervals
[k delta,(k+1)delta). This is a covering number up to absolute constants,
not exact cardinality. Let I_delta be the maximum number of *distinct exact
normalized outputs* F_lambda(Gamma_B) in any such interval. It is not
the number of ordered pairs landing in that interval.

**PROVED — C-BRIDGE.** Suppose B subset [-1,1]. Partition any good pair
set into difference strips G_j with centers u_j in [-2,2], |u-u_j|<=r;
the remaining b ordered pairs are bad. Choose

    r <= min(1,sqrt(delta/(7lambda))).                   (C.4)

Then the error in (C.3) is at most delta. Define
K_j=N_delta^grid(ell_j(G_j)), using the actual conditional support.
One occupied projection cell can move into at most four output grid
cells, since its delta-neighborhood has length 3delta. Consequently

    |P(A,A)| <= 4 I_delta sum_j K_j + b.                 (C.5)

If distinct normalized outputs are separated by more than delta then
I_delta=1. To prove (C.5), first cover good outputs using the enlarged
projection cells, then use the per-cell population bound; charge at most
one further output for each bad pair. The exact affine output map in
(C.1) preserves support cardinality. Overlap of output covers only makes
this upper bound looser. It never justifies dropping the number of strips.

The interval [-2,2] can be partitioned with at most ceil(2/r)+1 such
strips. Writing mu_j=|G_j|/n^2, their masses sum to 1-b/n^2. A conditional
projection estimate on G_j has to use that support size and measure,
and every exceptional strip or exceptional pair contributes its entire
mass to b. Without another estimate one has only K_j<=|G_j| and
sum K_j<=n^2-b, which gives no saving. Bounding the number of pairs in
a projected cell is a different assertion from bounding its occupied
support or its distinct exact output population.

Thus a sufficient **missing hypothesis for this route**, with all losses
explicit, is

    I_delta sum_j K_j = O(n^(2-epsilon)),
    b = O(n^(2-kappa)),      epsilon,kappa>0 fixed,        (C.6)

at a proved compatible scale and on a proved growing carrier. Then (C.5)
gives an exact-image saving with c=min(epsilon,kappa) and a fixed prefactor.
This is a proved implication with an unproved antecedent, not a construction.
Neither entropy nor a projection lower bound proves the upper estimate
in (C.6). No expansion theorem has been used in the wrong direction.

## C5. Entropy, support and the success test

**PROVED — C-ENT.** For a uniform ordered input pair and exact output Z,
write r(z)=#{(a,b) in A^2:P(a,b)=z}. Then

    H(Z)=2 log n - (1/n^2) sum_z r(z) log r(z),
    |P(A,A)|=sum_(a,b in A) 1/r(P(a,b)).                 (C.8)

The first follows from Pr(Z=z)=r(z)/n^2; the second gives one unit per
nonempty fiber. Shannon entropy satisfies H(Z)<=log|support|. A small
Shannon entropy does **not** supply an upper bound on support. Quantized
entropy H(floor(Z/delta)) concerns a different random variable; it equals
the exact entropy only when quantization is injective on outputs.

For B's finite scout the exact values are

    H(Z)=log 196 -(5/98)log 5,
    log|support|=log 188,
    |support|=186+10/5=188.

At the separated scale above, quantized and exact entropies agree; at
a coarser scale cells can merge unrelated exact values. Without C-SEP or
a proved I_delta, no exact support upper bound follows from small covering
number or quantized entropy.

Finally, if all but at most C n^(2-kappa) pairs have actual r>=n^epsilon,
then (C.8) yields

    |P(A,A)| <= C n^(2-kappa)+n^(2-epsilon).             (C.9)

This uses the **actual** all-pair tail, including isolated vertices. Large
energy sum r^2, selected collision edges and a few large components do
not supply that tail. For the scout, every threshold 1<K<=5 has bad mass
186; for K>5 all 196 pairs are bad.
