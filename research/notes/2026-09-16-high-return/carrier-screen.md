Date: **16 September 2026**. Track: **T03, separate high-return multiplier
branch**, fixed polynomial $Q(x,y)=x^2+xy+y^2$. These are scoped constructions
and proofs, not an alteration of the actual adaptive-radical frontier.

**Authorization/scope:** the current user commissioned concrete high-return

The parent cycle controls any later scouting budget. The arguments below were

from the new scoped deductions.

Put $\omega^2+\omega+1=0$, $\pi=2-\omega$, and

$$u=\frac{8+5\omega}{7}=\frac{\bar\pi}{\pi},\qquad
T=T_u=\frac17\begin{pmatrix}8&5\\-5&3\end{pmatrix},\qquad
T^{-1}=\frac17\begin{pmatrix}3&-5\\5&8\end{pmatrix}.$$

Here $7=\pi\bar\pi$, $N(u)=1$, and multiplication on
$z=a-\omega b$ agrees with $T(a,b)$. Normalize the split valuations so that
$v_\pi(\pi)=v_{\bar\pi}(\bar\pi)=1$. Then
$v_\pi(u)=-1$, $v_{\bar\pi}(u)=1$, and $u$ is non-torsion. For any finite
real $A$, let $R_{\langle u\rangle}(a,b)$ count all integer powers $k$ such
that $T^k(a,b)\in A^2$. For nonzero pairs this count is finite, and it bounds
the count using any finite chosen subset of powers. The zero pair is always
excluded from this notation and charged separately.

The split-valuation rules used below have a self-contained elementary proof
in [denominator-obstruction.md](denominator-obstruction.md), section
“Elementary split valuations at 7.” They require no unique-factorization
theorem: the two residue evaluation maps have prime kernels, which establish
additivity and unequal-valuation noncancellation directly. The names
$\pi,\bar\pi$ in this file are interchanged relative to that proof; the
multiplier $u=(8+5\omega)/7$ is the same in both files.

## HR-5 — simultaneous Cartesian repair

**PROVED, new scoped obstruction.** This explicit closure family cannot solve
the fixed $Q$ target, and its entire cyclic group has only logarithmically many
returns at each nonzero pair.

### Construction and input growth

Start $A_0=\{-1,0,1\}$ and define

$$A_{j+1}=A_j\cup\operatorname{coord}(T(A_j^2))
                 \cup\operatorname{coord}(T^{-1}(A_j^2)),$$

where $\operatorname{coord}$ is the union of both coordinate projections.
Thus every pair at stage $j$ returns under $1,u,u^{-1}$ into the next stage.
The definition uses one common scalar input set and includes the entire old
Cartesian square.

Let $n_j=|A_j|$ and $B_j=7^jA_j$. Induction gives

$$B_j\subset\mathbb Z,\qquad \max|B_j|\le13^j.$$

Indeed every row of either integer numerator matrix has absolute row sum at
most $13$, and old coordinates become $7B_j$ at the next cleared scale.
Also $(8A_j+5A_j)/7\subset A_{j+1}$. The ordered-set sum inequality
$|X+Y|\ge|X|+|Y|-1$ therefore gives

$$n_{j+1}\ge2n_j-1,\qquad
2^{j+1}+1\le n_j\le2\cdot13^j+1.$$

The sum inequality follows by listing an increasing chain of $|X|+|Y|-1$
distinct sums, first along one row and then along one column. Thus this
growth claim does not require a conjecture about collisions in the closure.

### Full-image obstruction

Since $\max|B_j|\le13^j\le n_j^{\log_2 13}$, the inherited integer
polynomial-height theorem applies. For every fixed $\eta>0$,

$$|Q(A_j,A_j)|=|Q(B_j,B_j)|\ge n_j^{2-\eta}$$

for all sufficiently large $j$. Consequently no fixed positive target
exponent holds along this family. This uses the formally inspected source
`T03_RESEARCH_RECORD_20260910.zip::output/Q_New_Mechanisms_Offline_Report.md`,
Theorem 7.1; its proof bounds integer norm fibers using the divisor bound.
The inherited theorem is not claimed as newly established here.

### Direct return obstruction

For a nonzero pair at stage $j$, put
$z_0=7^j(a-\omega b)\in\mathbb Z[\omega]$. If $T^k(a,b)\in A_j^2$, then
$u^kz_0$ is integral. Therefore

$$-v_{\bar\pi}(z_0)\le k\le v_\pi(z_0).$$

There are at most $1+v_7(Nz_0)$ such integers. Since
$1\le Nz_0\le3\cdot13^{2j}$,

$$R_{\langle u\rangle}(a,b)
\le1+\log_7(3\cdot13^{2j})=O(j)=O(\log n_j).$$

Thus no fixed positive return exponent is possible even if every power is
offered. This argument counts actual possible returns from above; it does
not confuse a small supplied multiplier list with all norm-one multipliers.
It concerns the cyclic group generated by the stated $u$ only.

The closure does supply a useful finite interior: every pair of
$A_{j-r}^2$ has $2r+1$ returns into $A_j^2$. But

$$\frac{n_{j-r}}{n_j}\le2^{-r}+\frac{1-2^{-r}}{n_j}.$$

Hence that guaranteed interior occupies at most approximately $4^{-r}$ of
the final pair space. This is the size of the *certified interior*, not an
assertion that every other pair has few returns; the preceding valuation
bound supplies the actual uniform return obstruction.

## HR-6 — compatible orbit thickening of a small box

**PROVED, new scoped cyclic-return obstruction; OPEN actual image rate.**
This architecture already combines a Cartesian seed with its norm-preserving
orbit. The following theorem rules out a positive return exponent for the
whole cyclic group on the explicit seed $H=1$. It does not lower-bound the
full image using other norm coincidences.

Put $P=\{-1,0,1\}$ and, for $J\ge0$, define

$$Z_J=\{T^j(a,b):(a,b)\in P^2,\ |j|\le J\},\qquad
A_J=\operatorname{coord}(Z_J),\qquad n=|A_J|.$$

Both coefficient signs occur because the seed is symmetric. This differs
from a simultaneous repair closure: only the original nine seed pairs are
rotated, and subsequent cross-pairs are counted without being repaired.
It is related to the historical cyclic-orbit constructions; the new
statement here concerns returns on the **whole completed Cartesian square**,
rather than only its engineered-pair density.

### Input, denominators, and engineered coverage

The eight nonzero seed pairs have norms $1$ or $3$, hence both split
valuations zero. Their images at exponent $j$ have valuations $(-j,j)$.
For $j\ne0$, recovering either rational coefficient from $z,\bar z$ uses
coefficients that are units at $7$ and denominator $\omega-\bar\omega$,
also a unit at $7$. Unequal-valuation noncancellation gives

$$v_7(a)=v_7(b)=-|j|.$$

For example, coefficient recovery is
$b=(\bar z-z)/(\omega-\bar\omega)$ and
$a=(\omega\bar z-\bar\omega z)/(\omega-\bar\omega)$.
At each nonzero valuation level there are at most
$2\cdot9\cdot2=36$ projected coefficients: two exponents, nine seed pairs,
and two coordinates. At valuation zero there are just $\pm1$.
Consequently, with $m_v=|\{a\in A_J\setminus\{0\}:v_7(a)=v\}|$,

$$m_v\le36,\qquad 2J+3\le n\le36J+3.$$

The lower bound uses at least two distinct signed nonzero coefficients at
each exact denominator level, together with $0,\pm1$.

Every coordinate has absolute value at most $2$: norm preservation gives
$Q(a,b)\le3$, while $Q(a,b)\ge3a^2/4$ and similarly for $b$.
All denominators divide $7^J$. Distinct nonzero seed/exponent labels give
distinct engineered pairs: their split valuations recover $j$, after which
invertibility recovers the seed. Thus

$$|Z_J|=8(2J+1)+1,\qquad |N(Z_J)|=3.$$

The completed grid nevertheless has $n^2$ pairs. Its unengineered part is
$n^2-|Z_J|=n^2-O(J)$; the three engineered norms are not an all-pairs bound.

### Every nonidentity return meets a small exceptional class

Let

$$E=\{(a,b)\in A_J^2\setminus\{(0,0)\}:v_7(a)=v_7(b)\},$$

using $v_7(0)=+\infty$. Then

$$|E|=\sum_vm_v^2\le36(n-1).$$

If the two rational coordinate valuations differ, the two split valuations
of $a-\omega b$ are equal to their minimum. Call such a pair *balanced*.
Multiplication by $u^k$ changes its split valuations by $(-k,k)$.
Therefore a nonidentity return cannot have both source and target outside
$E$. For any fixed $k\ne0$, invertibility gives at most $2|E|$ return edges.

There is also a finite uniform range of possible exponents. For a nonzero
pair, $z_0=7^J(a-\omega b)$ is integral with

$$Nz_0\le12\cdot7^{2J}.$$

Integrality at the target requires
$-v_{\bar\pi}(z_0)\le k\le v_\pi(z_0)$, so
$|k|\le2J+1$. There are at most $4J+2$ nonidentity powers. Summing the edge
counts, including the identity separately, yields

$$\sum_{(a,b)\ne(0,0)}R_{\langle u\rangle}(a,b)
\le n^2-1+2(4J+2)|E|\le145n^2.$$

Thus, for every $M>0$, at most $145n^2/M$ nonzero pairs have at least $M$
returns. For fixed $\alpha>0$, a threshold $M=n^\alpha$ is met by an
$O(n^{-\alpha})$ fraction. The required nearly full rich tail is impossible
for this architecture and this cyclic action.

This is an **average-return obstruction**, used in the correct direction
through the elementary inequality $M|\{R\ge M\}|\le\sum R$. It is not an
inference from collision energy to an image upper bound. The cleared height
is exponential in $n$, so the polynomial-height theorem from HR-5 does not
automatically rule out its actual $Q$ image. Allowing other norm-one
multipliers is outside the return theorem.

## HR-8 — compatible integer translates of the coordinate orbit

**PROVED, same scoped cyclic-return obstruction.** A distinct additive
architecture is

$$C_J=\operatorname{coord}\{T^k(1,0):|k|\le J\},\qquad
B_J=\{-1,0,1\}+C_J.$$

This is the literal translate family, with no extra signed completion.
The orbit has norm one, so $|c|\le2/\sqrt3$ and every $b\in B_J$ has
$|b|<3$. For $|k|=h\ge1$, both orbit coordinates have exact rational
valuation $-h$ by the same unequal-valuation argument. Adding an integer
preserves this valuation. There are at most $2\cdot2\cdot3=12$ values at
each such level. The level-zero part is exactly $\{-1,0,1,2\}$.

The second coordinates at $k=h$ and $k=-h$ are opposite nonzero numbers.
They give at least two distinct elements at each negative valuation level.
Consequently

$$2J+4\le |B_J|\le12J+4,\qquad m_v\le12.$$

The common denominator divides $7^J$ and the norm of each scaled pair is
at most $27\cdot7^{2J}$. Since $27<7^2$, every returning exponent still
satisfies $|k|\le2J+1$. With $n=|B_J|$, the same balanced-pair argument
now gives $|E|\le12(n-1)$ and

$$\sum_{(a,b)\ne(0,0)}R_{\langle u\rangle}(a,b)
\le n^2-1+2(4J+2)\,12(n-1)\le49n^2.$$

Thus at most $49n^2/M$ pairs have $M$ returns. Compatible translations
by this fixed three-element set do not create a positive cyclic return
exponent. This conclusion still leaves unrelated norm-one multipliers and
the actual full-image rate open.

## HR-7 — full cyclotomic digit boxes and torsion rotations

**PROVED, new scoped return-size obstruction; OPEN sparse variants.**
Finite-order actions avoid non-torsion denominators but must be large enough
relative to the scalar input set.

Choose an integer $M\ge3$ divisible by $3$, $H\ge1$, and a primitive
$M$-th root $\zeta$. Set $K=\mathbb Q(\zeta)$,
$L=K\cap\mathbb R$, and

$$Z_{M,H}=\left\{\sum_{j=0}^{M-1}c_j\zeta^j:
c_j\in\{-H,\ldots,H\}\right\}.$$

Then $K=L(\omega)$, with the fixed chosen cube root in $K$. Write each
$z$ uniquely as $a_z-\omega b_z$, $a_z,b_z\in L$, and take $A$ to be the
signed union of all these coefficients. The real embedding is injective;
no trace projection is being used to discard dimensions.

Multiplication by $\zeta$ cyclically permutes the displayed digit positions,
so $Z_{M,H}$ is exactly invariant. Every nonzero orbit has length $M$, and
its relative norm is constant. This supplies an engineered norm bound
$|N(Z_{M,H})|\le1+(|Z_{M,H}|-1)/M$.

**EXTERNAL RESULT — degree/basis input only.** The irreducibility of
$\Phi_M$ and the equality $[\mathbb Q(\zeta):\mathbb Q]=\varphi(M)$ are
stated in MIT RES.18-012, *Algebra II Student Notes*, Spring 2022, Lecture
31, Fact 31.7 and its following paragraph, printed page 139
([primary source, PDF page 139](https://ocw.mit.edu/courses/res-18-012-algebra-ii-student-notes-spring-2022/mit18_702s22_full_lec.pdf#page=139)).
The lead checked this primary source on 16 September 2026; it was not
independently reopened by this subtask. Precisely this fact is imported to
obtain the rational power basis, not any image or return estimate.

The first $d=\varphi(M)$ powers therefore form a rational basis. Setting all
other digits to zero gives $(2H+1)^d$ distinct elements. Since every element
has both coefficients in $A$, with $n=|A|$,

$$n^2\ge|Z_{M,H}|\ge(2H+1)^{\varphi(M)}.$$

The supplied torsion group has only $M$ elements. Even perfect returns on
every Cartesian pair would therefore have exponent at most

$$\frac{\log M}{\log n}
\le\frac{2\log M}{\varphi(M)\log(2H+1)}.$$

This tends to zero as $M\to\infty$. For an elementary bound, the prime-power
formula for $\varphi$ gives $\varphi(M)\ge\sqrt{M/2}$: each odd prime-power
factor contributes at least its square root, as does every power of $2$
except $2^1$, whose deficit is $\sqrt2$. For bounded $M$ and $n\to\infty$,
the torsion-group size stays bounded instead. Thus no sequence of these full
digit boxes supplies a fixed positive return exponent from this action.

Cartesian completion adds another unpaid requirement:

$$|Q(A,A)|\le |N(Z_{M,H})|+n^2-|Z_{M,H}|.$$

No useful deficit estimate is proved here. The argument excludes the full
digit-box architecture as a torsion-return certificate, not every sparse
cyclotomic code, alternative action, or actual image saving. A sparse code
would need a new distinct-input count and nearly full Cartesian coverage.
