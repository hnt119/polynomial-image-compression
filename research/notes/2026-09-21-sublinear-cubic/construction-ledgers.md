## 1. Authorization, evidence, and parameter order

The current attachment commissions new offline research on scalar reuse and
sublinear common inventories. Frozen CR/GS proofs remain inputs. No network,
external theorem, novelty check, arithmetic amplification, historical gadget
rerun, ordinary-AP optimization, or old 192-graph rerun was used.
The announced ceiling was 64 carriers, 384 graphs, two million exact polynomial
evaluations, and ten million counted checks. Actual use is recorded in
[verification](verification.md) and the experimental companion.

For SC-Q1–Q3 fix the positive nonsquare integer \(D\) first. Then choose the
stated widths and scales before counting the full square. There is no growing
field degree. For the balanced critical-scale theorem also fix \(\kappa>0\)
before \(L\) grows. For SC-D1/D2 take any changing primes satisfying the stated
congruence, and actual integer index sets satisfying the width restriction;
no prime-density theorem is assumed. For reverse-fiber candidates first fix
the exact parameter ranges, deduplicate scalar values and \((z,u)\) labels,
and then enumerate all resulting scalar pairs.

All new proof claim IDs, quantifiers, source locators, dependencies and audit
scopes appear in the main report's claim ledger and its proof companions.
Historical missing digital/rich-fiber originals are not proof dependencies.

## 2. Quadratic projection and changing scale

The construction is \(A=t+h\{a+b\sqrt D:0\le a<L,\ 0\le b<K\}\).
SC-Q1 uses \(\beta=\sqrt{|h^2(h^2)'|}\) when \(h^2\in\mathbb Q(\sqrt D)\).
SC-Q2 restricts to \(K=L,\ h^2\in\mathbb Q,\ h^2L\ge\kappa>0\).

| Gain or cost | Exact charge | Evidence and disposition |
|---|---|---|
| Input lower and upper counts | \(N=LK\) exactly | Irrationality makes the two input coefficients unique |
| Same-set real transport | Actual real embedding; both coordinates use \(A\) | Translation contributes only \(2t\); scaling retains the fixed polynomial and changes the equality coefficient to \(h^2\) |
| Input thinning, twice | None for Q1; Q2 selects at least \(\gamma_DN^2\) actual source pairs solely for an image lower bound | No selected set replaces the full square in a support upper bound |
| Parameter/projection fibers | One for the basis rectangle | Output coefficient faithfulness fails, but input injectivity is proved |
| Coefficient and denominator cost | Width \(W=L-1+\sqrt D(K-1)\); scale enters through \(\beta\) or \(h^2L\) | A shrinking real scale alone cannot be treated as a free gain |
| Archimedean distortion | Both real substitutions bounded by \(2W\) for the sum difference | The product of the two scale magnitudes is charged; either can vary |
| Field degree and discriminant | Fixed degree two and fixed \(D\) | Used only for an elementary nonzero integer product, not a field-tower construction |
| Regulator, units, splitting, local moduli | Inapplicable to these direct equalities | No arithmetic amplification or lattice-packing theorem invoked |
| Branches and multiplicities | All integer difference vectors in a displayed quadratic band; at most \(N\) anchors each | Both signs and both substitutions are included |
| Inventory | Arbitrary, even unrestricted size | Actual-fiber obstructions apply before selecting any steps |
| Exceptions / full square | Q1 explicitly bounds all nonsingleton vertices; Q2 bounds entire fibers of a fixed positive fraction of vertices | Incidental and cross-coordinate pairs included |
| Actual image | Balanced unscaled: \(N^2-O_D(N^{3/2}\log(2N))\); critical scale: at least \(c_{D,\kappa}N^2\) | FAILED construction family in these regimes |
| Rates, balanced \(L\) | With depth \(d=\log L\): \(a=B=2\), output rate \(4\), no local saving, \(\delta=0\) | No fixed power saving; no boundary exponent asserted |

For anisotropic boxes Q1 retains exact \(N=LK\) and
\(O_D(Nm(1+\sqrt{T/\beta}))\) exceptional vertices, where
\(m=\min(L,K),T=\max(L,K)\). This becomes \(o(N^2)\) if
\(\beta T\to\infty\). Small \(\beta T\) is an unresolved scope boundary.
For \(h^2\notin\mathbb Q(\sqrt D)\), Q4 proves exact injectivity rather
than a favorable rate.

## 3. Genuinely many-to-one three-parameter projection

Project \((a,b,c)\in[0,L-1]^3\cap\mathbb Z^3\) to
\(a+b\sqrt D+c(\sqrt D)^2\), with fixed \(D\) and \(L\ge D\).

| Gain or cost | Exact charge | Consequence |
|---|---|---|
| Formal input descriptions | \(L^3\) | Not the scalar input count |
| Actual scalar lower and upper count | \(N=((D+1)(L-1)+1)L\asymp_D L^2\) | Exact image is a bounded-aspect quadratic coefficient rectangle |
| Projection multiplicity | Exact \(\mu(r)\) in SC-Q3; maximum \(\lceil L/D\rceil\), average \(L^3/N\asymp_D L\) | Two-coordinate counting must use \(N^2\), not \(L^6\) |
| Two-coordinate loss | Formal \(L^6\) descriptions become \(\Theta_D(L^4)\) actual pairs | Loss is order \(L^2\), paid before any compression estimate |
| Output and all exceptions | \(N^2-O_D(N^{3/2}\log(2N))\) outputs | All actual cross-pairs covered by Q1 |
| Degree, heights and distortion | Fixed degree two; first coefficient reaches \((D+1)(L-1)\) | Fixed aspect ratio and both substitutions charged |
| Local/arithmetic costs | No splitting, modulus, regulator, tower, or arithmetic amplification used | Inapplicable, not an uncounted gain |
| Rate | Actual \(a=B=2\), output \(4\), \(\delta=0\) in depth \(\log L\) | FAILED specified projection family |

This is an exact algebraic family with controlled scalar multiplicity.
The failure is stronger than observing that the projection has many fibers:
after deduplication, its actual cubic image is still asymptotically quadratic.

## 4. Growing prime denominator and exact residue descent

Take \(A=a+B/p\), \(B\subset\mathbb Z\), \(N=|B|\), width \(W\), prime
\(p\ge5\), \(p\equiv2\pmod3\), and \(2W<p^2\).

| Gain or cost | Exact charge | Evidence |
|---|---|---|
| Input lower and upper count | \(N=|B|\) exactly | Affine input map injective |
| Same-set projection | Both scalar coordinates are divided by the same \(p\) | The identity \(p^3(P-2a)=d^3+p^2(i+j)\) retains the fixed cubic |
| Denominator / coefficient height | Input denominator \(p\), output clearing factor \(p^3\), explicit index width \(W\) | The entire congruence argument keeps both \(p^2\) and \(p^3\) effects |
| Residue populations | \(n_r\), \(H=\sum n_r^2\) | SC-D1 isolates off-residue pairs; no density factor applied to an ambient box |
| Input thinning, twice | Each subcarrier contributes exactly \(n_r^2\) actual pairs | SC-D2 sums all residue squares and charges all \(N^2-H\) cross-residue pairs |
| Output overlap | Different residue-square images are proved disjoint | Exact output decomposition, not assumed independent savings |
| Archimedean cost | Within-class integer spacing, diameter at most \(W/p\) | Frozen GS-U3 applies only after the exact confinement proof |
| Exceptional vertices | At most \(\sum n_r\min(n_r,F(W/p))\le NF(W/p)\) | Every nonsingleton actual fiber is charged |
| Step inventory | Arbitrary size | Not needed for the actual-image obstruction |
| Field degree/discriminant/regulator/splitting | Degree one; other costs inapplicable | Elementary prime congruence only, no arithmetic amplification |
| Full image and rate | If \(W/p=o(N^2)\), image \(N^2-o(N^2)\), rate gap zero | FAILED specified fine-mesh family |

The nonuniform explicit family \(B_p=\{j+p\lfloor j/3\rfloor:0\le j<p\}\)
has \(N=p\), one scalar per residue, width \(W=\Theta(p^2)\), scalar
diameter \(\Theta(p)\), and exact image \(N^2\). It has tiny gaps \(1/p\)
while escaping the previous whole-carrier moderate-width condition.
Its rates in depth \(\log p\) are \(a=B=1\), output \(2\), \(\delta=0\).

## 5. Reverse fibers and the new finite candidate grid

For any actual finite prescribed label set \(F\), SC-R1 uses \(Q=|F|\)
distinct ordered pairs and \(N\) distinct required scalar values. It charges
exactly \(2Q\) coordinate occurrences. A certificate using long prescribed
components must pay \(N^2-Q\) unprescribed pair outputs before any incidental
collisions are known. The desired regime needs \(Q=N^2-O(N^{2-\delta})\)
and average scalar reuse \(2Q/N\asymp N\).

The grid records every formal parameter and its scalar projection, the
distinct prescribed labels, actual scalar values, rational denominator,
numerator/denominator heights, diameter, minimum scalar gap and minimum gap
in \(A-A\). All \(N^2\) actual outputs and actual graph vertices are then
counted. Thus projection collisions cannot silently inflate \(N\).

Declared construction inventories are fixed by their listed basic scales
and their cardinality caps before output enumeration. Frequent-useful-step
inventories and all-useful inventories are explicitly diagnostics derived
from the already computed fibers. Their finite success at connecting fibers
is not an independent construction or support theorem.

For the best reported reverse-fiber example, \(N=29\) and the explicit
10-step graph has 262 edges, 167 nonisolated vertices, 723 components and
723 actual outputs. It leaves 674 isolated vertices out of \(841\). Even
though all actual fibers are connected, this is not almost-full coverage.
The maximum fiber/component size is seven; no asymptotic lower input rate,
common-inventory exponent, or polynomial exception bound is proved for this
finite model.

For the changing-scale completion tests, only the three declared levels are
part of the experiment. The denominator sequence changes with depth, and all
formal completion words and actual multiplicities are retained. No indefinite
recurrence or asymptotic support estimate follows from those three levels.
