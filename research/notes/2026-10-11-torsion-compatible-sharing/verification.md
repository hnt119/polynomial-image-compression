no floating-point proximity is used for equality. The five imported
certificate checks are a proof audit, not a new attachment search.

For a finite pole-free parameter set X and nonconstant scalar map φ of
degree d, each value has at most d preimages, so |φ(X)|≥|X|/d. If
X+T=X, evaluation of any fixed slot list after translation gives the
same list of frames. It cannot add distinct pairs. With k fixed prescribed
pairs per parameter, Q≤kM≤kdN when a degree-d slot image is contained
in A. An isogeny or cover changes the charged degree, rather than
removing this inequality. This elementary accounting is separate from
the imported EG-B3/B4 finite-grid bounds; neither is a universal actual-image
lower bound.
