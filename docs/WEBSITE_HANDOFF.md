## Public overview

How many distinct values can a polynomial take when both inputs range over the same finite set of real numbers? Motivated by constructions for unit distances and sum–product problems, Huang Yixuan studied sets where many different input pairs give exactly the same output. The project gives a construction for the square of any fixed integral linear form plus an integral linear term. Its arithmetic input comes from a field tower used in unit-distance research. Counting square residues throughout that tower yields a power saving for the entire polynomial image. The archive also records four open quadratic, cubic and quartic targets. It explains why some promising families have too many outputs and identifies the precise estimates still needed for others.

## What the project contributes

**PROVED in the project theorem system.** For each fixed $a,b,c,e\in\mathbb Z$, $P=(ax+by)^2+cx+ey$ admits a fixed $\varepsilon_P>0$ and growing finite $A_j\subset\mathbb R$ with $|P(A_j,A_j)|\le |A_j|^{2-\varepsilon_P}$. The same scalar set supplies every ordered pair, including the diagonal. This includes degenerate coefficients. $ab(ae-bc)\ne0$ singles out nonspecial examples. The September C0.1 statement assumed primitivity and nonvanishing. The November all-coefficient theorem has its own proof. [Theorem 1 and counting proof](https://github.com/hnt119/polynomial-image-compression/blob/c689ab52ca3bb9e3221bd09ae9a083a3111e39df/research/proofs/c0-v5/theorem-and-proof.tex) · [September corrections and November provenance](https://github.com/hnt119/polynomial-image-compression/blob/bd1f2d663262821575eebdfa559b7c25f76b46ab/research/exports/2026-11-05-report-references/README.md#ref10)

The project constructs the real set by embedding and scaling a box of algebraic integers in a totally real field. A simultaneous supply of split primes and fields of increasing degree is **EXTERNAL RESULT**, Proposition 3.8 of *Planar Point Sets with Many Unit Distances*. The project's contribution counts the input box and every possible polynomial output, then transfers the estimate to real scalars using a common scaling. [Project argument, MP-03–07](https://github.com/hnt119/polynomial-image-compression/blob/c689ab52ca3bb9e3221bd09ae9a083a3111e39df/docs/release/2026-11-05/shared-quadratic.md) · [External manuscript, Proposition 3.8](https://cdn.openai.com/pdf/74c24085-19b0-4534-9c90-465b8e29ad73/unit-distance-proof.pdf#page=12)

## Findings the website may quote

- **PROVED necessary condition.** For the plus-sign cubic, a fixed full-image saving forces almost every input pair to share its exact output in different subrectangles at logarithmically many scales. The six small exact examples are finite diagnostics. [MC-S1–S3, proof and finite scope](https://github.com/hnt119/polynomial-image-compression/blob/3973f97457902cb3954c417fa264d67d47cd8daa/research/notes/2026-10-21-multiscale-collisions/README.md)
- **PROVED family-specific obstruction.** The balanced-factor family for $x^2+xy+y^2$ has image $\Theta(n^2)$. Its proof bounds full fibers, including targets outside the selected symmetry actions. Other real carriers remain possible. [BFF-O1, §§1–5](https://github.com/hnt119/polynomial-image-compression/blob/bd1f2d663262821575eebdfa559b7c25f76b46ab/research/exports/2026-11-05-report-references/README.md#ref15)
- **PROVED supply, OPEN returns.** A different quadratic carrier has at least $2^{d_j}$ eligible norm-one units at one fixed radius $T_*$, with total logarithmic height bounded by $d_j L(T_*)$. A unit only counts as a return when its transformed pair belongs to the same input square. Several occupied unit orbits can give the same polynomial value. [MS-O1 arithmetic, §§2–5](https://github.com/hnt119/polynomial-image-compression/blob/bd1f2d663262821575eebdfa559b7c25f76b46ab/research/exports/2026-11-05-report-references/README.md#ref12) · [MS-O2 incidence identity, §§2–4](https://github.com/hnt119/polynomial-image-compression/blob/bd1f2d663262821575eebdfa559b7c25f76b46ab/research/exports/2026-11-05-report-references/README.md#ref13)
- **PROVED implication, CONDITIONAL application.** A homogeneous quadratic witness with a sufficiently small difference set would transfer to $x^2+xy+y^2+x$. A growing witness satisfying both premises is missing. This affine benchmark has a separate identity from the T01 cubic. [Norm–trace transfer, §2.3](https://github.com/hnt119/polynomial-image-compression/blob/bd1f2d663262821575eebdfa559b7c25f76b46ab/research/exports/2026-11-05-report-references/README.md#ref11)
